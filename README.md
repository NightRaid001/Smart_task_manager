# Smart_task_manager

This project is a command-line task manager that allows users to create, manage, and organize their tasks efficiently. It provides features such as adding new tasks, marking tasks as completed, deleting tasks, and listing all tasks. 
The task manager is designed to be simple and user-friendly, making it easy for users to keep track of their to-do lists and stay organized. 

The project is implemented in Python and uses JSON files for data storage, ensuring that user data is preserved across sessions.

Also includes unit tests to ensure the reliability and correctness of the task management functionalities.

For user instructions and usage, please refer to the documentation provided in the project repository.
